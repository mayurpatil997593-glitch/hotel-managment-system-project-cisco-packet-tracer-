# Enterprise Network Design Using Cisco Packet Tracer

## Project Overview
This project demonstrates the design and configuration of a multi-department enterprise network using Cisco Packet Tracer. The network includes three routers (F1, F2, F3), switches, PCs, printers, and wireless access points.

## Features
- VLAN configuration for eight departments.
- DHCP configuration for automatic IP address assignment.
- Inter-VLAN routing using Router-on-a-Stick.
- Static routing between routers.
- Trunk and access port configuration.
- Network connectivity testing using ping commands.
